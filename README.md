# Alexan – IA autónoma de código

Alexan es una Inteligencia Artificial que:
* Escucha tu voz (Whisper + OpenAI).
* Detecta y corrige código.
* Ejecuta el código de forma segura.
* Devuelve la salida y un resumen de la corrección.

Este es el repositorio base; puedes ir añadiendo código y pruebas aquí.
